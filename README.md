# Notas (site da Safira)

Site gerado com [Quartz 4](https://quartz.jzhao.xyz/) (licença MIT) e publicado no GitHub Pages: https://gustavodsb1.github.io/notas

O conteúdo da pasta `content/` é enviado pelo plugin **Safira Publicar**: ele copia a pasta `Publicar` do cofre para cá e faz o push. A cada push, o GitHub Actions gera o site e o publica.

Para criar o seu próprio site: clique em **Use this template**, ative **Settings → Pages → Source: GitHub Actions**, troque `baseUrl` em `quartz.config.ts` e cole o endereço do repositório nas configurações do plugin Safira Publicar.
